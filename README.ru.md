# Навыки Filament v5

[![GitHub stars](https://img.shields.io/github/stars/itsbuyru-bit/filament-v5-skills?style=flat-square)](https://github.com/itsbuyru-bit/filament-v5-skills/stargazers)
[![License: MIT](https://img.shields.io/badge/License-MIT-brightgreen.svg?style=flat-square)](LICENSE.md)

Агентский навык (skill), описывающий стандарты кода, архитектурные паттерны и лучшие практики разработки на
[Filament](https://github.com/filamentphp/filament) **v5**.

Каждое правило в этом навыке проверено по исходному коду `filamentphp/filament` на теге **`v5.10.1`** — чтением
реальных исходников пакетов, а не пересказом документации и не по памяти. Там, где документация самого
фреймворка отстаёт от кода, приоритет отдан коду, а расхождение отмечено явно.

## Как использовать

**С агентом, который читает навыки из репозитория** — укажите ему путь
`.github/skills/filament-v5-development/SKILL.md`.

**В любом другом окружении** — скопируйте каталог навыка туда, где ваш инструмент ожидает навыки, либо вставьте
`SKILL.md` в контекст напрямую. Оба файла самодостаточны и ссылаются только друг на друга.

**У Filament есть и собственный агентский навык** —
`packages/panels/resources/boost/skills/filament-development/SKILL.md`, устанавливается через
`php artisan boost:install` → **Agent Skills** → `filament/filament (skills)`. Этот навык — более глубокое
дополнение к нему; §19 в `SKILL.md` согласует оба документа в местах пересечения.

## О миграции на v5

Filament v5 сохранил большинство имён методов из v3/v4 как алиасы с пометкой `@deprecated`, которые молча
проксируют вызов в новый метод. Статический анализ и линтеры их **не** подсветят — именно поэтому это самый
вероятный способ притащить устаревший код в приложение на v5. Два примера, на которых спотыкаются чаще всего:

- `Table::bulkActions()` устарел в пользу **`toolbarActions()`** — и *не* `groupedBulkActions()`, который
  является отдельным, актуальным удобным методом.
- Пространство имён `Filament\Tables\Actions` всё ещё существует, но содержит единственный enum
  (`HeaderActionsPosition`) и **ни одного класса действия**. Все действия живут в `Filament\Actions\*`.

Полный список — в §16 файла `REFERENCE.md`.

## Проверка достоверности

API, упомянутый в этих файлах, был машинно сверен с чекаутом v5.10.1:

- каждое упомянутое имя класса, enum и интерфейса;
- ~250 упомянутых имён методов и artisan-команд;
- каждое **отрицательное** утверждение — те ~24 имени, про которые навык заявляет, что их в v5 *нет*.

## О языке навыка

Сейчас на русский переведён только этот README — он даёт обзор репозитория и требований.

Сами `SKILL.md` и `REFERENCE.md` оставлены на английском намеренно:

- это технический справочник примерно на 160 КБ, где почти каждая строка — имя метода, FQCN или пример кода;
- перевод такого объёма неизбежно расходится с оригиналом при каждом обновлении, а расхождение в справочнике по
  API вреднее, чем отсутствие перевода;
- агенты читают `SKILL.md` как машинную инструкцию, и английский здесь — наименее рискованный вариант.

Если русская версия навыка нужна — это отдельная задача, и лучше делать её как полный перевод с пометкой
актуальности, а не как частичный. Скажите, если нужно.
